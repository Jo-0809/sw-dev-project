# 놓칠뻔

경상국립대 재학생이 지원 자격을 충족하는 행사·공고를 놓치지 않도록, 참여 조건을 자동 판정해 알려주는 서비스입니다.

공지를 모아주는 서비스가 아니라, 내가 지원할 수 있는 것만 골라주는 서비스입니다.

## 1. 비즈니스 목표

학기 말 기준, 지원 자격을 충족하는 행사 공지 중 마감까지 열람하지 않은 비율 20% 이하

판정 결과와 열람 기록이 모두 시스템 내부에 남기 때문에 별도 설문 없이 집계합니다. 추출이 불확실해 `확인 필요`로 분류된 공고는 분모에 포함하며, 미열람으로 계산합니다.

실제 지원 여부는 측정하지 않습니다. 저희가 통제할 수 있는 범위는 기회가 있다는 사실을 인지시키는 데까지이고, 알고도 지원하지 않은 것은 사용자의 선택이기 때문입니다.

## 2. 사용자 요구사항

| # | 요구사항 | 대응 기능 |
|---|---|---|
| R1 | 여러 곳에 흩어진 공지를 일일이 찾아다니고 싶지 않다 | 관심 출처 등록, 공지 자동 수집 |
| R2 | 공고 전문을 읽고 자격을 직접 대조하고 싶지 않다 | 참여 조건 항목별 추출 |
| R3 | 내가 지원 가능한 것만 보고 싶다 | 지원 자격 자동 판정 |
| R4 | 판정 결과를 믿을 수 있어야 한다 | 판정 근거 항목별 표시 |
| R5 | 마감을 놓치고 싶지 않다 | 마감 임박 알림, D-day 달력 |

## 3. 사용자 이용 흐름

### 최초 1회 — 온보딩

1. 가입
2. 학적 프로필 등록 — 학년 · 학과 · 학점 · 재학 상태
3. 관심 출처 등록 — 학과 공지, 교내 공지, 외부 행사 사이트

### 백그라운드 — 시스템 자동 수행

4. 등록 출처를 주기적으로 확인해 신규 공고 감지 및 저장 (중복 제거)
5. 공고 본문에서 참여 조건을 항목으로 추출 — 학년 · 전공 · 학점 · 신청 기간 · 배제 조항
6. 추출 조건과 사용자 프로필을 대조해 가능 / 불가 / 확인 필요 판정, 항목별 충족 여부 기록
7. 가능 판정 공고 중 마감 임박 건에 대해 알림 발송 예약

### 반복 — 사용자 일상

알림 수신 → 지원 가능 목록 확인 → 상세에서 판정 근거 확인 → 원문 링크로 이동해 신청

목록에는 지원 가능 공고만 마감 임박순으로 표시하며, `확인 필요` 공고는 별도 표시와 함께 노출합니다.

추출 신뢰도가 낮은 공고를 `불가`로 버리지 않고 `확인 필요`로 남기는 이유는, 잘못 걸러내 기회를 잃는 것이 가장 나쁜 실패이기 때문입니다.

실제 신청은 원문 페이지에서 이루어집니다. 신청 대행은 범위에 포함하지 않습니다.

## 5. 스프린트 계획

스크럼 기반으로 3회 반복하며, 각 스프린트 종료 시점을 수업 발표에 맞췄습니다. 중요도 8인 항목을 첫 스프린트에 모두 배치하여, 1차 데모에서 이미 핵심 가치인 자격 판정이 동작하도록 구성했습니다.

### 스프린트 1 — 4~8주차 · 30점

| 항목 | 추정치 |
|---|---|
| US-01 관심 출처 등록 | 3 |
| US-02a 단일 출처 공지 수집 | 5 |
| US-03 프로필 입력 | 3 |
| US-04a 핵심 참여 조건 추출 (학년·전공·학점) | 5 |
| US-05 지원 자격 자동 판정 | 5 |
| US-06 판정 근거 표시 | 3 |
| 계정 / 프로필 저장 구조 | 3 |

데모 — 출처 한 곳을 등록하면 공고가 수집되고, 내 프로필과 대조해 지원 가능 여부가 근거와 함께 표시된다

데모 — 여러 출처를 통합 수집하고, 지원 가능 공고를 마감 임박순 목록으로 제공한다

## 6. 최종 데모 시나리오

1. 프로필 입력 — 3학년 / 항공우주공학 / 학점 3.4
2. 관심 출처 등록 — 학과 공지 게시판 외 2곳
3. 수집된 공고 24건 중 지원 가능 7건 · 확인 필요 3건 자동 분류
4. 공고 상세에서 판정 근거 확인 — 3학년 이상 충족 / 학점 3.0 이상 충족 / 중복 수혜 해당 없음
5. 마감 임박 알림 수신 후 알림에서 원문 링크로 이동
6. 학기 미열람 비율 집계 화면 — 비즈니스 목표 달성 여부 제시

- `main`에 직접 커밋하지 않습니다
- 기능 개발은 `feature/기능이름` 브랜치에서 진행합니다
- 작업은 이슈로 등록하고, Pull Request로 병합합니다
- 커밋 메시지는 `[US-01] 관심 출처 등록 화면 추가` 형식으로 백로그 항목과 연결합니다
